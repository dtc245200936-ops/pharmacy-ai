# Pharmacy AI - Hệ Thống Quản Lý Nhà Thuốc

Ứng dụng web hỗ trợ quản lý nhà thuốc, bán hàng và tích hợp trợ lý AI.

## Công nghệ sử dụng
- **Frontend:** React, Vite, React Router DOM, Tailwind CSS / CSS Modules
- **Backend:** Node.js, Express (đang phát triển)

## Hướng dẫn cài đặt & chạy dự án

### 1. Cài đặt Frontend
```bash
cd frontend
npm install

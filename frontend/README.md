# HỆ THỐNG QUẢN LÝ NHÀ THUỐC CÓ TÍCH HỢP AI

## 1. Giới thiệu

Đây là dự án xây dựng hệ thống quản lý nhà thuốc có tích hợp AI nhằm hỗ trợ quản lý thuốc, kho hàng, bán hàng và tra cứu thông tin thuốc.

Hệ thống hướng đến việc giảm thao tác thủ công, hạn chế sai sót trong quá trình quản lý và hỗ trợ người dùng tra cứu thông tin bằng AI.

## 2. Công nghệ sử dụng

### Frontend
- ReactJS
- Vite
- JavaScript
- HTML/CSS

### Backend
- Node.js
- API

### AI
- AI hỗ trợ tra cứu và tóm tắt thông tin thuốc

## 3. Chức năng chính

- Đăng nhập và phân quyền người dùng
- Quản lý thuốc
- Thêm, xem, sửa, xóa thuốc (CRUD)
- Tìm kiếm thuốc theo mã hoặc tên
- Quản lý nhập kho
- Quản lý bán hàng
- Thống kê
- Trợ lý AI
- Cảnh báo thuốc sắp hết hạn và tồn kho thấp

## 4. Chức năng quản lý thuốc

Chức năng quản lý thuốc cho phép:

- Thêm thuốc mới
- Xem danh sách thuốc
- Sửa thông tin thuốc
- Xóa thuốc
- Tìm kiếm thuốc

Thông tin thuốc gồm:
- Mã thuốc
- Tên thuốc
- Danh mục
- Đơn vị tính
- Giá bán
- Số lượng tồn kho
